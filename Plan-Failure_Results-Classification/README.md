This folder contains the failure classification script and result CSV file for the Plan-and-Act model's failed tasks. The first column in the CSV file is the task id, and the second column is the corresponding failure type. The classifier uses DeepSeek as an LLM-as-a-Judge. Compared to the Base Model classifier, the system prompt is adapted for the Plan-and-Act architecture: it instructs the judge to distinguish between failures caused by a flawed planner-generated plan versus failures caused by the executor's own actions during trajectory execution.
